# Smart PDF Price Finder

اپ اندرویدی برای مدیریت چند PDF کاتالوگ/لیست قیمت و جستجوی هوشمند در نام کالا، شرح، کد، مدل، مشخصات و قیمت.

## قابلیت‌ها
- افزودن همزمان چند PDF
- نمایش همه فایل‌های اضافه‌شده در پنجره برنامه
- حذف هر فایل
- نگهداری لیست فایل‌ها بعد از بستن برنامه
- استخراج متن صفحات PDF با PDFBox-Android
- جستجوی فارسی/انگلیسی با نرمال‌سازی ي/ی، ك/ک و ارقام فارسی/عربی
- تطبیق دقیق، بخشی و فازی (Edit Similarity)
- امتیازدهی نتایج برای پیدا کردن کالا حتی با تفاوت تایپی/نوشتاری
- تلاش برای استخراج کد/مدل و قیمت از متن اطراف نتیجه
- نمایش فایل، صفحه، کد، نام، قیمت و درصد تطبیق
- کاملاً آفلاین پس از نصب و بدون ارسال PDFها به سرور

## نکته مهم درباره «هوش مصنوعی»
هسته نسخه اول یک موتور جستجوی هوشمند محلی است، نه یک مدل مولد ابری. این انتخاب باعث می‌شود PDFهای قیمت و اطلاعات تجاری روی گوشی باقی بمانند و برای هر جستجو نیاز به API Key نباشد. موتور از نرمال‌سازی، token matching، fuzzy matching و امتیازدهی عددی استفاده می‌کند.

برای PDFهای اسکن‌شده که متن واقعی ندارند، مرحله OCR باید به نسخه بعدی اضافه شود. PDFهای متنی/دیجیتال به‌صورت مستقیم قابل ایندکس هستند.

## GitHub Actions
فایل `.github/workflows/android.yml` با Java 17 و Gradle 8.10.2، APK دیباگ را می‌سازد و با نام `smart-pdf-price-finder-apk` به‌عنوان Artifact ذخیره می‌کند.

## OCR برای PDFهای اسکن‌شده
این نسخه هنگام پردازش، صفحه‌هایی را که متن قابل استخراج ندارند با Tesseract LSTM OCR بررسی می‌کند. مدل‌های `fas` (فارسی)، `ara` (عربی) و `eng` (انگلیسی) در اولین استفاده به‌صورت خودکار از `tessdata_fast` دریافت و در فضای خصوصی برنامه نگهداری می‌شوند. این باعث می‌شود نام کالا، شرح، کد، برند و قیمت داخل PDFهای عکس‌محور نیز قابل جستجو شود. برای PDFهای متنی، OCR اجرا نمی‌شود مگر اینکه صفحه فاقد متن قابل استخراج باشد.

> OCR یک مدل تشخیص متن است و دقت آن به کیفیت اسکن، رزولوشن، فونت و چیدمان جدول وابسته است. برای قیمت‌های حساس، نتیجه را با صفحه اصلی PDF تطبیق دهید.
